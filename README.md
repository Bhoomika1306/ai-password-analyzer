# 🔐 AI Password Strength Analyzer

A full-stack application that uses Machine Learning to analyze password strength, predict vulnerability risk, and provide smart suggestions.

## 🚀 Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React + Vite + Tailwind CSS |
| Backend | Python Flask |
| ML | Scikit-learn Random Forest |
| Icons | Lucide React |
